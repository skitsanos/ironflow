# IF-094 — Lease-loss regression still races hosted-runner scheduling

## Outcome and validation

**Historical status:** Resolved on 2026-08-05.

Develop CI run `30922850749` failed on its first attempt because
`lost_lease_stops_as_infrastructure_and_is_durably_stalled` did not observe the
delay task start inside its one-second polling window. The retry passed the
same regression and the complete default suite, confirming a scheduling flake
rather than a product regression. IF-072 had separated the polling window from
the first heartbeat, but still depended on the executor starting a real delay
node before an arbitrary deadline.

Required outcome:

- synchronize the lease fault with the test node's actual execution start;
- exercise the real JSON lease renewal and expired-lease reconciliation paths;
- retain only a generous deadlock watchdog, not timing as test coordination;
- keep the coordinator test surface modular and below the project's preferred
  300-line module size;
- leave public node behavior, Lua examples, and node documentation unchanged.

Resolution: the regression now uses a dedicated pending test node that signals
when its `execute` future begins. A focused state-store wrapper gates the first
heartbeat on that signal, asynchronously expires the real JSON lease, then
delegates renewal and reconciliation to `JsonStateStore`. This guarantees the
lease loss happens after work starts without polling durable state or assuming
how quickly the runtime schedules the task. The coordinator still proves that
lease loss surfaces as an infrastructure error and durably leaves the run
`Stalled` with the interrupted task terminalized as `Failed`.

The test moved into a focused 203-line lease-loss submodule; its coordinator
test parent is 118 lines. The regression passed 20 consecutive focused stress
runs plus a final focused run. `cargo fmt --all -- --check`, the 447-module size
policy, exact all-target Clippy with warnings denied, and `git diff --check`
passed. No full integration gate, live storage service, Lua example validation,
or deployment test was run because this change affects only deterministic test
coordination around the embedded JSON store.
