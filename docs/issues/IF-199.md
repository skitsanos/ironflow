# IF-199 — Default SQLite store URL breaks for store directories containing spaces, percent signs or question marks

## Evidence and boundary

Review of `develop` at 1.21.1-dev.1 on 2026-11-12, reproduced with a local
optimized build and a one-step flow on the default backend.

| `--store-dir` | Result |
|---|---|
| `plain` | success |
| `My Runs` (relative) | `Failed to connect SQL state store: error with configuration: invalid domain character` |
| `runs%41data` | `(code: 14) unable to open database file` |
| `a?b` | `unknown query parameter` while parsing the connection URL |
| absolute path with a space | success |
| `My Runs J` with `IRONFLOW_STORE=json` | success |

- In every failing case the directory had already been created.
- `resolve_url` (`src/cli/sql_config.rs:65-84`) formats the raw path into
  `sqlite://{path}?mode=rwc`. sqlx parses it as a URL: the first relative
  component becomes a host, `?` starts the query, and the path is
  percent-decoded, so `%41` opens a different directory than the one that
  was created and protected. If the decoded directory exists, the database
  silently lands outside the private store directory.
- `IRONFLOW_STORE_URL=sqlite::memory:` is accepted and fails at startup with
  `duplicate column name: started_micros`: each pooled connection gets its
  own empty in-memory database.

Boundary: the default `data/runs` and ordinary absolute paths work, which is
why the suites pass. By reading only, Windows drive-letter and backslash
paths (`C:\ironflow\runs`, `.\runs`) take the same parsing route and would
fail; Windows is a release target and is not in CI. Since IF-163 this path
is the default for every installation; the JSON store accepted any
directory.

## Required outcome and acceptance

- Build the SQLite connection from a filesystem path
  (`SqliteConnectOptions::filename`) or percent-encode an absolutized path,
  so any valid directory name works and nothing is decoded.
- Reject in-memory SQLite URLs for the state and event stores, or pin their
  pool to one connection, with a clear message.
- Regressions: relative and absolute directories containing a space, `%41`,
  `?` and `#`; an in-memory URL; and a Windows-style path test that runs on
  the Windows release job or a documented manual check.
- Do not create the directory before the URL is known to be usable, or
  remove it on failure.
