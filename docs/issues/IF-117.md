# IF-117 — Missing nested tool-input paths fall back to the entire root object

## Required outcome and acceptance

- Resolve the complete requested nested path without falling back to its root object.
- Specify and document missing-path behavior as an error or explicit missing value, never a wider data selection.
- Test present/missing nested fields, literal values, and a private sibling field that must not enter tool messages.

## Evidence and cause

Fresh review on 2026-09-12, finding R12. See
[AUDIT_2026-09-12.md](./AUDIT_2026-09-12.md) for the reviewed candidate,
evidence boundaries, and complete finding-to-issue mapping.

[Source: tool_dispatch/call_context.rs:85](../../src/nodes/composition/tool_dispatch/call_context.rs).

Mapping `ctx.user.id` when `id` is absent returns the full `user` object. A synthetic unrelated private field then appeared in tool-result messages. Missing paths should fail or have an explicit missing-value contract, never broaden selection silently. Evidence: engine tool-context probe.

## Progress

Open. Implementation and regression validation are pending.
