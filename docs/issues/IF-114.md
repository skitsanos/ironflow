# IF-114 — PDF split/merge discard inherited page attributes

## Required outcome and acceptance

- Resolve inherited Resources, MediaBox, CropBox, and Rotate before replacing page parents in split and merge.
- Keep selected-page isolation from IF-112 and existing object/memory limits intact.
- Compare source and output text, dimensions, rotation, and rendering using a valid inherited-attribute fixture; distinguish native rendering from metadata-only assertions.

## Evidence and cause

Fresh review on 2026-09-12, finding R09. See
[AUDIT_2026-09-12.md](./AUDIT_2026-09-12.md) for the reviewed candidate,
evidence boundaries, and complete finding-to-issue mapping.

[Split source: split.rs:150](../../src/nodes/image/pdf_merge_split/split.rs), [merge: graph.rs:52](../../src/nodes/image/pdf_merge_split/merge/graph.rs).

Reparenting does not materialize inherited Resources, MediaBox, and Rotate. A valid synthetic source rendered and extracted text with Poppler; its split rendered blank with missing-font errors, and the merged output changed from a rotated 200x100 page to unrotated Letter defaults. Both nodes reported success. Flatten inherited attributes before reparenting; test text, dimensions, rotation, and rendering. Poppler PNGs and CLI outputs are in the extraction evidence directory.

## Outcome and validation

Resolved locally on 2026-09-12 with [IF-112](./IF-112.md), after published
baseline `7c5c803`. Both nodes resolve the nearest non-null Resources, MediaBox,
CropBox, and Rotate entries before reparenting. Explicit page overrides win;
resource dictionaries are inherited as whole values, not merged with more
distant ancestors. Indirect resources retain shared identity. Broken or cyclic
Parent chains fail, and inherited resources count toward merge's existing
retained-object limit.

The pre-fix regressions demonstrated missing MediaBox values for split and
merge, and the real CLI/Poppler comparison showed a blank Letter-sized split
instead of the source's rotated/cropped 140 by 220 pixel page. Post-fix tests
preserve text, fonts, image XObjects, boxes, rotation, null fallback, explicit
overrides, and source ordering. Five graph integration tests and seven merge
unit tests pass; the full focused matrix and required checks are recorded in
IF-112.

Native validation is a separate, reproducible opt-in test:

```bash
cargo test --test test_pdf_page_rendering -- --ignored --nocapture
```

It requires `pdftoppm` and `pdftotext` from Poppler. One test passed: an actual
CLI flow splits the first page and merges two copies of the two-page source.
At 72 DPI using the CropBox, the split page and all four merged pages match
their source pages pixel-for-pixel, including inherited fonts and an image.
Source dimensions are 140 by 220 and 300 by 200 pixels. Poppler also extracts
the expected selected-page text. The retained split PNG was visually inspected.
Set `IRONFLOW_KEEP_PDF_TEST_OUTPUT=1` to retain a fresh temporary evidence
directory; normal runs clean it up. The test is explicitly ignored in the
ordinary suite because Poppler is an external runtime dependency.

Documentation and both Lua examples describe page-level fidelity, without
promising preservation of catalog features, document signatures, or redaction
of hidden content. This is local uncommitted work, not a deployed PDF-service
test or a new full-feature integration-gate result.
