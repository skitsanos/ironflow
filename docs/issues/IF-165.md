# IF-165 — Module-size gate optimizes file length while functions stay complex

## Evidence and boundary

Audit of `develop` at 1.20.1-dev.6 on 2026-10-28.

- `scripts/check_module_size.py` (280 lines) with `module_size_policy.json`
  (nine exceptions, budget nine, hard cap fourteen) and
  `scripts/tests/test_check_module_size.py` enforce a 300-line target and
  400-line hard limit in pre-commit, the CI policy job and the gate.
- Strict Clippy on `--lib` the same day
  (`-W clippy::too_many_lines -W clippy::cognitive_complexity`) reported 26
  findings. Functions over 100 lines: `src/lua/runtime/api.rs` 216,
  `src/engine/executor/task_runner.rs::run_task` 212,
  `src/engine/executor/workflow.rs::run` 197,
  `src/nodes/extract/docx_parser.rs` 196, `src/nodes/ai/llm.rs` 185,
  `src/nodes/composition/subworkflow.rs` 161, `src/api/handlers/flow.rs` 143,
  `src/engine/executor/finalizer.rs` 121, `src/cli/mod.rs` 116,
  `src/nodes/http/request.rs` 109,
  `src/nodes/composition/parallel_subworkflows.rs` 107,
  `src/api/handlers/validate.rs` 104. Cognitive complexity above the default
  25: `workflow.rs::run` 63, `task_runner.rs::run_task` 48,
  `lease.rs::heartbeat_with_timing` 43, `lua/runtime/loader.rs` 40,
  `lua/sandbox.rs` 40, `error_handler.rs` 38, `finalizer.rs` 29,
  `docx_parser.rs` 29.
- Of 561 `src/**/*.rs` files, 44 are at most 30 lines and 63 are 31 to 60
  lines. Several exist only to declare submodules
  (`src/nodes/transform/xml.rs` 5 lines, `csv.rs` 6,
  `src/nodes/composition/conditional.rs` 8). Nesting reaches seven directories
  (`src/nodes/extract/xlsx/archive_preflight/tests`,
  `src/nodes/image/image_basic/resize/budget`).
- The gate counts test-only files: 78 files (10,479 lines) under `src/` are
  `tests.rs`, `*_tests.rs`, `tests/` directories or `test_support`;
  `src/storage/json_store/catalog/complexity_tests.rs` is three lines with
  three submodules because the cap applies to it.
- `evaluate()` treats a module shrinking below its reviewed ceiling as a
  violation, so every improvement to an excepted file requires a policy edit
  in the same change.

Boundary: IF-028 and IF-034 resolved the original 400-plus-line files and this
is not a regression of those. The finding is that the metric rewards file
splitting rather than function cohesion, and that the gate's own cost is high.

## Required outcome and acceptance

- Exclude test-only files from the gate by path convention, and merge trivial
  declaration-only files where cohesion improves.
- Replace shrink-is-violation with "shrinking is allowed; ceilings are lowered
  automatically or reported as a warning".
- Add function-level limits: `clippy.toml` with `too-many-lines-threshold` and
  `cognitive-complexity-threshold`, enabled as warnings first, with the
  current hotspots either refactored or allowed with a rationale, then
  promoted to `-D` in the required lint command.
- Update the Rust design rules in `AGENTS.md`, `test_check_module_size.py` and
  the policy JSON; keep the 400-line hard cap.
- Resolution evidence: gate output listing production files only, and the
  function lints green under the chosen thresholds.
