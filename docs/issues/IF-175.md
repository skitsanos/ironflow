# IF-175 — Flow source can abort the process during load and validation

## Evidence and boundary

Review of `develop` at 1.21.1-dev.1 on 2026-11-12, reproduced with a local
optimized build through `ironflow validate`.

1. Script-controlled sizes reach `Vec::with_capacity`.
   - `return { _name = "x", _steps = {}, _step_count = 1000000000000000 }`
     (70 bytes) ends with `memory allocation of 184000000000000000 bytes
     failed`, exit status 134.
   - Setting `__len` on a step's `dependencies` table to return the same
     number aborts the same way (`24000000000000000 bytes`).
   - `src/lua/runtime/extractor.rs:17-21` reads `_step_count` from the
     returned table and `:47-49` uses `Table::len()`, which honours `__len`.
     Builder state lives in ordinary, script-writable table fields
     (`src/lua/runtime/api.rs:23-26`).
2. Validation walks the syntax tree recursively.
   - A flow whose top-level chunk contains `local v = 1` followed by `+1`
     200,000 times (400 KB, under the 1 MiB source cap) ends with `thread
     'main' has overflowed its stack`. 20,000 terms pass on the CLI's main
     thread.
   - `collect_functions` (`src/lua/analysis.rs:143-157`) and the scope
     analyzer (`src/lua/analysis/scope.rs:63-78, 207-224`) recurse once per
     tree level. Left-associative operator chains parse into a tree as deep as
     the chain, and Lua's own compiler accepts them.

Both are aborts, not panics. The same loader serves `POST /flows/validate`
and `POST /flows/run` with inline source (`IRONFLOW_ALLOW_ADHOC_FLOWS`
defaults to `true`), webhooks, schedules and subworkflows, where server
threads have 2 MiB stacks.

Boundary: the HTTP paths were not executed; they share the code shown above.
An API key is required unless the server is unauthenticated on loopback.

## Required outcome and acceptance

- Never size an allocation from a script-supplied count: iterate with
  `raw_len`, enforce an explicit step and dependency cap, and use fallible
  reservation. Prefer keeping builder state out of script-writable fields.
- Replace the recursive tree walks with an explicit stack and a depth cap that
  returns a validation error.
- Regressions: both `_step_count` and `__len` inputs return a load error; a
  200,000-term expression returns a validation result on a 2 MiB thread; the
  API returns 4xx for each rather than losing the connection.
- Evidence: focused Lua runtime and validation tests, API validate test.
