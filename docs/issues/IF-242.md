# IF-242 — Recursive list_directory can inventory the wrong directory on Unix

## Evidence and boundary

Reviewed 2026-11-19 on local `develop` at `ae1f686`.

`src/nodes/file/directory.rs:88` converts the native entry path to a lossy UTF-8 string for JSON. Line 103 uses that display string for filesystem traversal. When a non-UTF-8 name and its replacement-character spelling coexist, the latter sibling can be traversed twice while the original children are omitted. Source inspection.

## Required outcome and acceptance

Use native paths for traversal. Either represent unencodable output paths distinctly or report them explicitly. Give the two siblings different marker files; require each exactly once with a distinguishable path, or a clear error instead of a successful incorrect listing.
