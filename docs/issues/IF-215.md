# IF-215 — Parsing, planning and fan-out paths that still do unbounded work

## Evidence and boundary

Recorded on 2026-11-13. Collected from the fixes for IF-173 to IF-175,
IF-188 and IF-189. Each item says how it was established; none was
re-verified for this page.

- (a) Measured: HTML parsing is quadratic in nesting depth, about 16 s for
  100,000 nested `<div>` in an optimized build. The Markdown paths stop early
  (IF-174); `extract_html` with `format = "text"` is uncapped, though it
  observes cancellation.
- (b) Measured: `html_to_markdown` output is not charged against an output
  limit. At the 128-level cap, 323 KB of input produced 20 MB.
- (c) Measured: `topological_phases` in `src/engine/recovery.rs` is
  quadratic; a 10,000-step dependency chain took 10 s to validate,
  unoptimized (IF-175).
- (d) By reading: `mcp_client` relies on `rmcp`'s fixed 16 MiB response cap;
  a reply of that size enters workflow context.
- (e) By reading: the `json_parse` node, unlike the Lua global fixed in
  IF-189, parses into a `serde_json::Value` with no node budget.
- (f) By reading: one S3 list page is read whole by the SDK, so an endpoint
  can still send one very large page.
- (g) By reading: each failed attempt stores one event of up to 64 KiB, and
  the retry count has no ceiling.
- (h) By reading: the nesting limit from IF-188 does not bound the total
  number of live child runs; wide `parallel_subworkflows` at each of sixteen
  levels multiply.

## Required outcome and acceptance

- Give each path an explicit budget that is enforced before or during the
  work, with a documented default in the limits table: nesting for
  `extract_html` text, output bytes for `html_to_markdown`, step count or a
  linear algorithm for (c), a response ceiling for `mcp_client`, the shared
  node budget for the `json_parse` node, a page-size ceiling for (f), a retry
  ceiling for (g), and a process-wide cap on live child runs for (h).
- Each gets a regression that fails fast with bounded memory or time.
- Items may be split into their own findings when work starts.
