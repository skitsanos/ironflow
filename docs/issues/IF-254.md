# IF-254 — Run inspection can mix the header and tasks of different runs

## Evidence and boundary

Reviewed 2026-11-19 on local `develop` at `ae1f686`.

`src/storage/sql_store/state_store.rs` reads the run header/context and `src/storage/sql_store/mod.rs:122` fetches tasks separately from the pool. If a terminal run is deleted and its ID reused between these reads, inspection can return the original header and context with the replacement tasks. IF-122 covers writes, not consistent reads. Source inspection.

## Required outcome and acceptance

Read from a consistent snapshot or detect replacement and retry. In deterministic SQLite and PostgreSQL tests, replace a run between reads; require a coherent old or new record or an explicit retry/error, never a mixture.
