# IF-244 — XLSX date and duration headers acquire literal JSON quotes

## Evidence and boundary

Reviewed 2026-11-19 on local `develop` at `ae1f686`.

`src/nodes/extract/xlsx/headers.rs:53` uses JSON `Value::to_string()` on the converted cell. For native Excel date/time and elapsed-time cells, `cells.rs` already produced a JSON string. Its JSON delimiters become part of the key, so looking up the displayed date or duration does not find the column. Source inspection.

## Required outcome and acceptance

Use the contents of string values, not JSON serialization. Extract a workbook with native date and elapsed-time headers and assert row lookup by the exact ISO text (for example `PT37H30M`) without embedded quotes. Preserve numeric, blank and duplicate-header behavior.
