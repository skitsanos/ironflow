# IF-256 — Subworkflow task attempts disappear from process metrics

## Evidence and boundary

At `ae1f686`, composition nodes created child engines without the parent's metrics registry. Only the calling step appeared in the task metrics; child attempts and retries were missing.

## Required outcome and acceptance

Propagate the process registry to child engines without double-counting the parent. With a synchronous child task failing once then succeeding, assert deltas of one failed and two successful attempts across parent and child. Cover the other child execution mode as applicable.

## Outcome and validation

Waiting, detached, parallel, repeated, and tool-dispatched child workflows inherit the parent's task metrics. A child task that succeeds on its second try and a successful calling step produce two successes and one failure in both the attempt counter and the duration histogram. The child does not add a second top-level run.
