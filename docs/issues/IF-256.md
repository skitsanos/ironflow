# IF-256 — Subworkflow task attempts disappear from process metrics

## Evidence and boundary

Reviewed 2026-11-19 on local `develop` at `ae1f686`.

`src/nodes/composition/subworkflow.rs:145` constructs a child engine without attaching the parent metrics registry. `src/engine/executor/engine.rs:41` defaults metrics to `None`. The parent subworkflow step is counted, but child task attempts and retries are not, contrary to the per-attempt contract in `docs/METRICS.md`. The later child-engine constructor needs the same review. Source inspection.

## Required outcome and acceptance

Propagate the process registry to child engines without double-counting the parent. With a synchronous child task failing once then succeeding, assert deltas of one failed and two successful attempts across parent and child. Cover the other child execution mode as applicable.
