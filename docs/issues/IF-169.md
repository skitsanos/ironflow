# IF-169 — Repository governance tooling outweighs the code it governs

## Evidence and boundary

Audit of `develop` at 1.20.1-dev.6 on 2026-10-28.

- `scripts/` holds 2,558 lines of TypeScript and Python and `scripts/tests/`
  another 1,732 lines; `.codex/hooks` holds 419 lines including its tests;
  `.claude/hooks` adds a protection script. Three agent configurations
  (`.agents/skills/*` with `agents/openai.yaml`, `.claude/skills/*` and
  `.codex/*`) describe overlapping release, check and issue workflows.
- `scripts/tests/repository_policy.test.ts` (19.5 KB) asserts the textual
  shape of CI, hook and gate files (for example "example validation reuses only
  the Linux release build" and "the integration gate package-cleans before
  work and after failure"). Every CI or gate change therefore needs a
  matching test edit.
- The CI `policy` job runs Python unittest for the hook tests and the
  module-size checker, Bun tests for every script, `validate_skills.ts`,
  `issues_registry.ts check` and actionlint; `.githooks/pre-commit` runs
  subsets selected by staged paths; the issue registry keeps 160-plus pages
  with a generated index and a generated compatibility index.
- Commit authorship: 506 of 628 commits by the maintainer, 109 by Renovate,
  12 by one other contributor. The coordination value of this tooling is low
  relative to its upkeep.

Boundary: the issue registry and the protected-path hooks are useful and stay.
The finding targets duplication and tests that restate configuration text.

## Required outcome and acceptance

- Inventory every script and script test and classify each as keep, merge or
  delete. Delete tests that only restate YAML or shell text; keep those that
  protect behavior (version bump, registry parsing, cleanup trap, target
  selection).
- Consolidate the three agent configurations into one canonical source with
  thin shims, removing duplicated skill text.
- Fold the `.codex/hooks` tests and the module-size checker tests into one
  policy test entry, and document the surviving set in `AGENTS.md` with the
  reason each exists.
- Resolution evidence: line counts of `scripts/`, `scripts/tests/`, `.codex/`,
  `.claude/` and `.agents/` before and after, with the CI policy job green.
