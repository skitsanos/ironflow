# IF-251 — MCP list_tools cannot discover tools beyond the first page

## Evidence and boundary

Reviewed 2026-11-19 on local `develop` at `ae1f686`.

`src/nodes/mcp/session.rs:71` always sends a default list request. Although the response can expose `nextCursor`, the node neither consumes it nor lets a workflow supply it. Repeating the action requests page one again. Source inspection.

## Required outcome and acceptance

Use a two-page fixture server. A workflow must be able to discover tools on both pages without knowing their names. Support explicit cursor continuation or bounded automatic pagination with a documented termination policy.
