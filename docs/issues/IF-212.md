# IF-212 — The outbound destination guard covers only the HTTP nodes

## Evidence and boundary

Recorded on 2026-11-13 from the consumer audit done while fixing IF-191. The
audit was by reading, by a search pass; two call sites were spot-checked.
Nothing here was executed against a network.

`block_private_network` exists on `http_request` and its method variants
only. No other node that opens a connection to a flow-controlled destination
honours it or has an equivalent:

- (a) `mcp_client` Streamable HTTP: `url` is unchecked. The `rmcp` transport
  uses its own `reqwest` client.
- (b) The shared provider client (`src/util/provider_http.rs`) behind `llm`,
  `ai_embed`, `ai_chunk_semantic`, `transcribe`, `slack_notification`,
  `send_email` through Resend and `arangodb_aql`: base URLs and OAuth token
  URLs can name internal hosts, and credentials are attached.
- (c) An `llm` custom provider with an absolute `chat_path`,
  `responses_path` or `path` replaces `base_url` entirely.
- (d) SMTP, `db_query` and `db_execute` connections, and S3 and s3vector
  `endpoint_url` have no restriction.
- (e) There is no process-wide setting that forces the guard on. Ad-hoc
  flows are allowed by default, so protection depends on each flow author.

Boundary: the guard is opt-in and these nodes never claimed it.
`docs/SECURITY.md` now lists exactly what is covered (IF-191). Operator-only
endpoints (artifact store, state and event stores) are out of scope.

## Required outcome and acceptance

- Decide the model first: a per-node option, a process-wide policy
  (`IRONFLOW_BLOCK_PRIVATE_NETWORK` or similar), or both. Record the choice.
- Apply the IF-191 classifier, with DNS pinning and redirect checks, to
  `mcp_client` Streamable HTTP and the provider client. For (c), either refuse
  an absolute path or classify its host.
- For (d), document that the guard does not apply, or add a host check where
  the driver allows one.
- Regressions per covered node: a literal and a DNS answer in a refused range
  are rejected before a connection; a public destination still works.
