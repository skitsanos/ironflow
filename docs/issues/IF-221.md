# IF-221 — Child input mappings and s3vector flags fall back silently on missing or malformed values

## Evidence and boundary

Recorded on 2026-11-13 from the audit done while fixing IF-192. All items
are by reading; none was executed.

- (a) `subworkflow` `input` mapping drops an entry whose parent context key
  is absent, so the child runs without that key and with no error.
- (b) `tool_dispatch` input mapping resolves a missing `ctx.` path to `null`,
  and treats a bare name that is not a context key as a literal string.
- (c) `s3vector_query_vectors` reads `strict`, `return_metadata` and
  `return_distance` as `false` when the value is not a boolean. A malformed
  `strict` therefore drops the cosine requirement for `min_similarity`.
- (d) The inline `filter` of `s3vector_query_vectors` is not interpolated, so
  `"${ctx.tenant}"` inside it is sent as literal text and matches nothing or
  the wrong thing.

Boundary: this is the class IF-192 fixed for `filter_key`: a value that
scopes or selects is replaced by a permissive default instead of failing.
The other `*_key` inputs were read and fail closed (listed in IF-192).

## Outcome and validation

Resolved on 2026-11-15. Every item was reproduced on the unfixed tree first.

**Decisions** (each is the fail-closed choice).

- One mapping contract for `subworkflow`, `parallel_subworkflows`,
  `repeat_subworkflow` and `tool_dispatch`: a string is a reference that must
  resolve, `{ optional = "<reference>" }` may be absent, `{ literal = <value> }`
  is passed as written. An absent optional entry is omitted in the three
  subworkflow nodes and is `null` in `tool_dispatch`, as each did before.
- In `tool_dispatch` only parent references (`ctx.<path>`, bare keys) must
  exist; `arguments.*` and `call.*` stay `null`, because the model supplies
  them.
- The flags accept what `config_bool` accepts, including boolean strings and
  templates; anything else fails.
- The inline `filter` is interpolated, not declared literal.

**Outcome.**

- (a) The audit added two nodes: `parallel_subworkflows` and
  `repeat_subworkflow` passed the string as text. All three raise a typed
  `InputMappingError` naming the entry, never the configured string, before
  any child starts. A non-object `input` is rejected; it inherited the parent.
- (b) Mappings of every tool the batch calls are checked before the first
  handler runs; `on_error = "ignore"` does not suppress the error.
- (c) A malformed flag fails before the client is built.
- (d) String values are interpolated once at any depth, keys are not, and a
  `filter_key` filter stays data. A placeholder that is missing, `null`, an
  object or an array fails.
- Audit of the other `s3vector_*` options: a non-string `endpoint_url` or
  `region` was ignored in favour of the environment or the default endpoint,
  and `top_k` / `dimension` above `i32::MAX` wrapped negative. Both now fail.
  `output_key` still defaults when it is not a string; it selects nothing.
  `foreach` takes no input mapping.

**Contract boundary.** Flows that passed text through a bare string, or
relied on a dropped entry or a `null`, need the explicit form;
`docs/releases/next.md` says how. The `s3_*` nodes ignore a non-string
`endpoint_url` the same way: read, not changed, outside this finding.

**Evidence.**

- Before: 7 of 9 new integration tests failed for (a) and (b), with the
  child's marker file written. For (c) and (d) a local endpoint received the
  request, with `"${ctx.tenant}"` in the body. The audit tests built a client
  from `endpoint_url = 8080` and wrapped both counts.
- After: `cargo test --lib` 787 passed, 1 ignored; `--test engine` 313,
  `--test cli` 108, `--test examples` 11, `--test nodes_network` 163,
  `--test serial -- --test-threads=1` 196, all passed. Failing cases assert
  no child marker and no request at the endpoint.
- All 163 `examples/**/*.lua` pass `ironflow validate`; the `11-subworkflow`
  flows and the `tool_dispatch` projection example were run.
  `parallel_subworkflows.lua` relied on the fallback and was changed.
- Formatting, the module-size check and all-target Clippy passed.
- Not run: live S3 Vectors, the PostgreSQL and Redis feature builds, the
  full integration gate.
