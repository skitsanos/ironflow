# IF-259 — Unix file-mode regression test loses the child exit status on failure

## Evidence and boundary

At `ae1f686`, the Unix file-mode test discarded the CLI exit status and searched combined stdout and stderr for `Status: success`. An intermittent failure produced a blank diagnostic. No incorrect permissions were observed, and the original termination reason is unknown.

## Required outcome and acceptance

Retain the exit status and check it explicitly. On failure report the current mask, exit code or signal, and captured stdout/stderr even if empty. Exercise a controlled unsuccessful child with no output to verify that its termination is diagnosable; do not paper over unexplained exits with retries.

## Outcome and validation

The test requires both a successful process exit and a `Status: success` line on stdout before checking permissions. Failure diagnostics include the octal umask, exit code or signal, and separately labeled stdout and stderr. Regression cases cover a silent nonzero exit, signal termination, and success text paired with a failing exit or written only to stderr. No retries were added.
