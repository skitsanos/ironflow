# IF-259 — Unix file-mode regression test loses the child exit status on failure

## Evidence and boundary

Reviewed 2026-11-19 on local `develop` at `ae1f686`.

In `tests/test_staged_output_modes.rs`, `write_under_umask` obtains a `std::process::Output` but returns only stdout and stderr joined with a newline. The caller checks for `Status: success` without retaining the exit code, signal or mask in the failure. In an isolated default macOS test run the assertion at line 386 failed with blank output. The exact test passed on immediate rerun. The original child exit reason and any underlying production defect are unknown; no incorrect file permissions were observed.

## Required outcome and acceptance

Retain the exit status and check it explicitly. On failure report the current mask, exit code or signal, and captured stdout/stderr even if empty. Exercise a controlled unsuccessful child with no output to verify that its termination is diagnosable; do not paper over unexplained exits with retries.
