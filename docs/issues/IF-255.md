# IF-255 — Restarting during a fall-back overlap can miss an in-grace fire

## Evidence and boundary

Reviewed 2026-11-19 on local `develop` at `ae1f686`.

`src/scheduler/mod.rs` seeds a local-clock watermark; `src/scheduler/evaluation.rs:84` enumerates through the current local time. On 2026-10-25 in Europe/Berlin, restarting at 01:05 UTC with 45 minutes of grace spans local 02:20 (first occurrence) to 02:05 (second occurrence). The first 02:30 fire was only 35 minutes ago, but this local window is reversed. When local time reaches 02:30 again, the intended instant is outside grace. Distinct from IF-059 duplicate-fire protection. Source inspection.

## Required outcome and acceptance

With `30 2 * * *`, the above fixed restart time, and no prior claim, assert one fire during recovery and no duplicate later in the repeated hour. Include a normal-day control and an already-claimed overlap fire.

## Outcome and validation

The scheduler maps the tick instant and the exclusive grace floor to the
latest local clock reading already reached. During the second pass through
a fold this is the last reading before the actual zone transition. The
window therefore includes all first-pass minutes reached so far, but never
the first minute after the fold before it is actually due. Grace is still
measured in elapsed time; occurrence identity, claim TTL and the rule that
only the most recent missed occurrence can start are unchanged.

Before the fix, deterministic scheduler tests returned no decision for the
Berlin restart above or at the exact 30-minute rollback on Lord Howe Island.
After the fix, Berlin starts once, a second scheduler using the same JSON
claim store reports `NotClaimed`, and neither starts it again. Separate
controls cover the first pass, a grace window entirely on the second pass,
a post-fold time not yet reached, and an ordinary winter day.

All 166 scheduler integration tests passed on macOS. The CLI strictly
validated the updated schedule example and ran its flow with the night-shift
context. No host clock was changed and no deployed service was exercised.

The complete default suite passed all 20 targets (2,793 passed, five ignored).
Formatting, module-size policy and `cargo clippy --all-targets -- -D warnings`
also passed.
