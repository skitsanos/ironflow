# IF-210 — Follow-ups recorded while fixing IF-186, IF-187 and IF-188

## Evidence and boundary

Recorded on 2026-11-12 from the three fixes. Each item says how it was
established. None was re-verified for this page, except (e), which was
measured during verification of IF-188.

Child workflows (IF-188):

- (a) By reading: the depth limit does not bound the total number of live
  children. Sixteen levels of wide `parallel_subworkflows` still multiply,
  and each level has its own `max_concurrent`. A process-wide cap on live
  child runs would close it.
- (b) Observed: `ironflow validate` does not load child flows, so a
  recursive flow is found only at run time, at the depth limit.
- (c) By reading: `IRONFLOW_MAX_REPEAT_ITERATIONS` is parsed in
  `repeat_subworkflow/config.rs`, outside `limits::ALL`, so a malformed value
  is not rejected at startup.
- (d) By reading: a child's steps do not inherit the parent step's deadline;
  they are stopped by cancellation when the parent times out.
- (e) Measured: a Lua function step is not a tracked worker. With
  `:timeout(2):on_error("handler")` on a function step that spends about 20
  seconds inside one `string.find` call, the handler started and the run
  finished `success` at 2 seconds while the function was still running; the
  process then exited at the five-second runtime bound from IF-183. The same
  happens when the function step is in a child flow. Built-in blocking nodes
  hold the step until the worker stops; function steps do not.

Guards (IF-187):

- (f) By reading: the load-time rejection of an undefined comparison runs in
  the Lua loader. A flow definition built without the loader gets only the
  runtime error.

File sources (IF-186):

- (g) By reading: of about 100 other interpolation call sites, 97 were judged
  to take configuration strings only. That judgement came from one pass and
  was not re-checked; the three defects found were fixed.
- (h) Observed: an HTTP body given as a bare artifact URI is sent as
  `application/octet-stream`, because only a descriptor carries the MIME
  type. Documented, but easy to miss.

Boundary: none of these is a regression from the three fixes. Earlier
follow-ups are in [IF-207](IF-207.md) and [IF-209](IF-209.md).

## Required outcome and acceptance

- Triage each item: fix it under this page, promote it to its own finding
  when it needs a design decision (likely (a), (b) and (e)), or close it with
  the reason.
- (e) needs a decision first: either function steps become tracked work that
  holds the step, or the documents state that a timed-out function step may
  keep running until it returns or the process exits.
- A fixed item gets a regression. Resolve the page when none is left.
