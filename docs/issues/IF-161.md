# IF-161 — GPL-3.0 html2md is linked into the MIT single binary

## Evidence and boundary

Audit of `develop` at 1.20.1-dev.6 on 2026-10-28.

- `Cargo.toml` declares `html2md = "0.2.15"` as a normal, always-enabled
  dependency; `Cargo.lock` resolves 0.2.17. The crate's registry metadata and
  its crates.io record give the license as `GPL-3.0+` (repository
  `gitlab.com/Kanedias/html2md`).
- Use sites: `src/nodes/extract/html/content.rs` (`parse_html_custom`, custom
  `TagHandler` implementations, `common::get_tag_attr`) behind the
  `extract_html` node, and `src/nodes/utility/markdown.rs` (`parse_html`)
  behind the `html_to_markdown` node.
- IronFlow is MIT (`LICENSE`, `license = "MIT"` in `Cargo.toml`).
  `.github/workflows/release.yml` publishes statically linked binaries for four
  targets in two feature variants and `container.yml` publishes images to GHCR
  and Docker Hub. Each artifact is a combined work that includes GPL code.
- No license gate exists. The CI `audit` job and `scripts/integration_gate.sh`
  run `cargo audit` (advisories only); there is no `deny.toml` or equivalent.
  A scan of the default resolved graph (571 crates) on 2026-10-28 found
  html2md as the only copyleft-only license; `r-efi` is tri-licensed with an
  MIT option.

Boundary: this is a distribution and licensing defect, not a runtime
vulnerability. Private source builds are unaffected; published binaries and
images are.

## Required outcome and acceptance

- Replace html2md with a permissively licensed HTML-to-Markdown conversion
  (candidates: `htmd` (MIT), or an in-tree converter over the
  `html5ever`/`markup5ever` stack already present through `ammonia`) that
  preserves the documented `extract_html` and `html_to_markdown` output
  contracts. `tests/test_extract_html_content.rs`,
  `tests/test_extract_nodes.rs` and `tests/test_shell_markdown_nodes.rs` must
  pass, or any contract change must be documented in `docs/nodes/`.
- Add a license policy gate to the CI `policy` job and
  `scripts/integration_gate.sh` (for example `cargo deny check licenses` with an
  allowlist of MIT, Apache-2.0, BSD, ISC, MPL-2.0, Unicode and Zlib, or a Bun
  script over `cargo metadata`) that fails on copyleft-only or missing
  licenses.
- Document the dependency license policy and shipped third-party notices in
  `docs/SECURITY.md` (fonts already ship `assets/fonts/OFL.txt`).
- Resolution evidence: the resolved graph without html2md, and the new gate
  failing on a seeded copyleft dependency before passing on the real graph.
