# IF-222 — Document extraction fidelity follow-ups for DOCX, PPTX and PDF metadata

## Evidence and boundary

Recorded on 2026-11-13 from the IF-193 fix, by reading. Items (b) to (e)
were each reproduced by a failing regression before the fix (2026-11-15).

- (a) Fixed under IF-193.
- (b) Fixed: `extract_word` comment anchors read the `mc:Fallback` copy of a
  text box (`ANCHOREDANCHORED`), and a range only the fallback declared
  failed the step.
- (c) Fixed: bold, italic and strikethrough resolve through
  `word/styles.xml` (`w:basedOn` chains, exclusive or of paragraph and
  character styles, document defaults). Table styles, `underline`, `color`
  and `highlight` are not resolved; a Markdown heading does not repeat its
  style's emphasis.
- (d) Fixed in `pdf_metadata` and `extract_pdf`: UTF-16LE marks and language
  tags in Info strings.
- (e) Fixed: `a:br` is a newline in slide and notes paragraphs and a space
  in a table cell and the title. Also fixed then: table-cell paragraphs were
  joined without a separator, and `a:buNone` paragraphs were list items.
- (f) Verified as far as the files allow; the rest is IF-225 to IF-227. On 2026-11-15 with pandoc 3.14 and `textutil` (both
  files are committed under `examples/fixtures/` and run by
  `test_tool_authored_documents`). On 2026-11-16 against the maintainer's
  private samples, read in place: only structure is recorded here and every
  new fixture is hand-built with made-up text.

## Sample run of 2026-11-16

Executed: every extractor on every sample through the CLI, compared by
script with the package XML or PDF objects, and with Poppler for the PDFs.

- Deck, PowerPoint 16: 86 slides (13 hidden), 83 notes pages, 551 text
  boxes, groups, 3 tables, `a:br`, 4 `mc:AlternateContent` without text.
  Slide and notes text matched the XML on every slide. Notes pages hold
  `sldImg`, `body` (`idx="1"`), `sldNum` (`a:fld type="slidenum"`) and, on 9
  pages, `ftr` with a plain run, as IF-193 assumed: no code change. `hdr`
  and `dt` occur on the notes master only.
- Fixed: list items were keyed on `lvl`, but PowerPoint writes none on a
  first-level bullet and declares bullets in `a:pPr` or the shape's
  `a:lstStyle`. 422 bulleted paragraphs were plain and 70 indented
  unbulleted ones were list items.
- Fixed: in the PDF written by the macOS Quartz context every `BT … ET`
  block was a line, so each glyph from a fallback font split its word (534
  tokens against Poppler's 423; identical after the fix). Lines now follow
  text position, using `/Widths` and `/W`. Found by reading and fixed:
  real-number `TJ` adjustments were not word gaps.
- Confirmed correct: PDF metadata; the image-only PDF (empty text);
  `pdf_to_image` and `pdf_thumbnail` of both PDFs, viewed beside `pdftoppm`
  renders; a document written by a generator library (headings, a 64-row
  table with `w:gridSpan`, style bold, empty `comments.xml`), whose repeated
  `Heading1` and `Heading2` ids resolve to the last definition (now
  pinned); three Excel workbooks (up to 16,007 rows; formulas, rich strings,
  currency formats), every cell equal to the sheet XML; four `.vtt` and one
  `.srt` file.

Validation, default features: `documents` 216 passed (3 ignored),
`examples` 11, `extract_execution` 2, the 38 extraction tests of `serial`
single-threaded, PDF unit tests; formatting, module-size check and
`cargo clippy --all-targets -- -D warnings` clean. Not run: the integration
gate and feature-enabled suites.

## Outcome and validation

Items (a) to (e) are fixed, and (f) is done for every structure the
available files contain. What they do not contain, and the decisions the
deck raised, are tracked on their own pages:

- IF-225: a `.docx` saved by Word or LibreOffice (text box, ranged comment,
  `w:rPrChange`, header, footer, footnote).
- IF-226: a `.pptx` with slide comments and a notes page showing the header
  and date placeholders.
- IF-227: a workbook with date cells.
- IF-228 (resolved): footer placeholder text (`ftr`, 70 slides) was part of
  slide text although notes omit it.
- IF-229 (resolved): bullets inherited from a layout or master were
  approximated from `lvl`.
- IF-224 (resolved): hidden slides carry `"hidden": true` in JSON.
