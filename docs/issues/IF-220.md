# IF-220 — Operational and validation follow-ups from the 2026-11 fix batches

## Evidence and boundary

Recorded on 2026-11-13. Small items left after the fixes for IF-173 to
IF-211. Each says how it was established; none was re-verified for this page.

- (a) Observed: a run record that cannot be decoded is skipped by
  reconciliation and can be deleted, but `inspect` still fails on it, the
  unbounded `StateStore::list_runs` fails on one, and a damaged lease file or
  Redis index key still fails a reconciliation pass (IF-181).
- (b) Observed: `POST /flows/validate` is still served during a drain
  (IF-183).
- (c) Decision needed: the five-second runtime shutdown bound is a constant
  with no configuration (IF-183).
- (d) Not run: the extended `scripts/replica_acceptance.ts` under Docker
  (IF-183).
- (e) Observed: `ironflow validate` does not load child flows, so a
  recursive flow is found only at run time (IF-188).
- (f) By reading: `IRONFLOW_MAX_REPEAT_ITERATIONS` is parsed outside
  `limits::ALL`, so a malformed value is not rejected at startup.
- (g) By reading: the load-time rejection of an undefined guard comparison
  runs only in the Lua loader (IF-187).
- (h) By reading: with `IRONFLOW_LUA_MAX_MEMORY_BYTES=0` only the node
  budget bounds `json_parse` (IF-189).
- (i) By reading: a detached child's flow load now holds the launching step
  until the load returns (IF-211).
- (j) Not reported upstream: the `calamine` style-table growth (IF-173) and
  the `lopdf` range walk that remains on its main branch (IF-178).
- (k) Cosmetic: `localhost.` with a trailing dot is refused by DNS
  validation, not by the literal-host check, so the error text differs.
- (l) By reading: both Redis stores use the client's default 500 ms response
  timeout, which is not configurable. Under load it failed six unrelated
  tests in one parallel run (IF-216).
- (m) By reading: the run-owned TTL test in `tests/test_redis_store.rs` uses
  fixed 1.2 s and 2 s sleeps around a short TTL, the pattern IF-216 removed
  elsewhere. It has not failed.
- (n) By reading: `html_sanitize` `link_rel` is neither interpolated nor
  type-checked; a non-string value silently uses the default (IF-195).
- (o) Observed: in `examples/20-date/date_format.lua` the handler log and the
  final log both write `log_message`, so its final value depends on step
  order.
- (p) By reading: `llm` in responses mode cannot complete a tool loop.
  `messages` and `tool_dispatch` are chat-only, so reported `function_call`
  items cannot be answered (IF-197).
- (q) By reading: a whitespace-only `llm` reply counts as usable, and a
  non-string `prompt` silently falls through to `input_key` (IF-197).
- (r) Observed: a blank `IRONFLOW_ARTIFACT_DIR` is accepted and the server
  starts; where artifacts are then written was not checked (IF-198).
- (s) By reading: a webhook `secret_env` variable of 16 or more spaces passes
  the length check in `src/api/webhook_signature.rs` (IF-198).
- (t) Decision needed: a blank `IRONFLOW_API_KEY` together with
  `IRONFLOW_ALLOW_UNAUTHENTICATED_API=true` serves unauthenticated even when
  `api_key` is set in the config file. Documented; it could fail instead
  (IF-198).
- (u) By reading: the embeddings OAuth path requires a numeric `expires_in`.
  A token response that omits it, or sends it as a string, fails, although
  the OAuth specification makes the field optional (IF-197).

## Required outcome and acceptance

- Triage as work allows: fix, or close with the reason. (d) needs one live
  run before the next release. (j) is the maintainer's decision.
- A fixed item gets a regression. Resolve the page when none is left.
