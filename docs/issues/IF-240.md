# IF-240 — Container publication ignores changes to shipped third-party notices

## Evidence and boundary

Reviewed 2026-11-19 on local `develop` at `ae1f686`.

`Dockerfile:53` copies `THIRD_PARTY_LICENSES.md` into the runtime image. The push paths in `.github/workflows/container.yml:6` omit that file. A notices-only commit on a publishing branch does not trigger a new build from that workflow. Static comparison of workflow and image inputs; no registry action was performed.

## Required outcome and acceptance

Include the notices file in the trigger (and the project license once packaged). Add a policy test that checks the runtime image inputs against the publishing trigger so a change to a shipped notice schedules a build.
