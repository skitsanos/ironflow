# IF-176 — Forwarded-header fragments become run-wide secrets and rewrite live step output

## Evidence and boundary

Review of `develop` at 1.21.1-dev.1 on 2026-11-12, reproduced against a local
`ironflow serve` with a webhook that lists one header in `forward_headers`.

- Header `X-Feature-Flags: beta=true,legacy=false`, flow with
  `step_if("ctx.amount > 100", "needs_approval", ...)` and `amount = 250`:
  the guard evaluates true, but its output `_route__if_needs_approval`
  becomes `"[REDACTED]"`, the guarded step is `skipped`, and the run reports
  `success`. Without the header the step runs.
- Header `X-Amzn-Trace-Id: Root=1-...;Parent=...;Sampled=1`: a code step
  returning `{ order1 = "first", total = 1, items = {1,2,3}, note = "room 101,
  1 item" }` is published as `total = "[REDACTED]"`, `items =
  ["[REDACTED]",2,3]`, `note = "room [REDACTED]0[REDACTED], [REDACTED]
  item"`, and the key `order1` is gone. The next step interpolates the
  rewritten values, so the corruption is in live context, not only in storage.
- Cause: `collect_secret_strings` (`src/util/redaction.rs:95-170`) adds the
  whole header value plus every `k=v` component split on `,` or `;`, header
  names, and JSON keys and scalars, with no minimum length.
  `src/util/redaction/owned.rs` then drops any key containing a secret and
  rewrites any string containing one, and `prepare_output`
  (`src/engine/executor/output.rs:63-70`) applies it before publication. The
  8-byte floor in `src/api/webhook_config.rs:162-171` covers the whole value
  only.

A sender who can set an allowed header can therefore suppress `step_if`
branches or blank fields in every later step.

Boundary: requires a webhook with `forward_headers`. IF-011 made whole-value
and structured scrubbing deliberate; the unbounded fragments and name/key
matching are the missed part. `docs/CLI_REFERENCE.md` describes
`forward_headers` as business metadata and documents literal-value redaction
only.

## Required outcome and acceptance

- Apply a minimum length to every derived token; stop treating header names
  and JSON keys as secrets; match short tokens exactly rather than as
  substrings.
- Never rewrite engine-reserved routing keys (`_route_*`,
  `_condition_result_*`) or change JSON types in live output; if a value must
  be withheld, fail the step visibly.
- Regressions: both headers above leave routing, numbers, keys and unrelated
  strings intact while the full header value is still absent from persisted
  runs and events.
- Update the webhook section of `docs/CLI_REFERENCE.md` and `docs/SECURITY.md`
  with the exact redaction contract.
